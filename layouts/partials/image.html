{{- $src := .Src -}} {{- $alt := .Alt -}} {{- $class := .Class -}} {{- $height := .Height -}} {{- $width := .Width -}} {{- $category := index . "Category" | default "" -}} {{- /* Priority: post-specific thumbnail from frontmatter */ -}} {{- $thumb := "" -}} {{- if $src -}} {{- $thumb = $src -}} {{- else -}} {{- $ctx := .Context -}} {{- if $ctx -}} {{- with $ctx.Params.thumbnail -}} {{- $thumb = . -}} {{- end -}} {{- end -}} {{- end -}} {{- /* Fallback: category-based SVG */ -}} {{- if not $thumb -}} {{- $thumb = cond (eq $category "AML") "/images/aml-thumb.svg" (cond (eq $category "Markets") "/images/markets-thumb.svg" (cond (eq $category "Science") "/images/science-thumb.svg" "")) -}} {{- end -}} {{- if $thumb -}} {{- $srcset := "" -}} {{- $phData := "" -}} {{- /* If thumbnail is a bare filename and the current page has resources, try to resolve as Page Resource */ -}} {{- $resolved := $thumb -}} {{- with .Context }} {{- $page := . -}} {{- if and (not (hasPrefix $thumb "/")) (len $page.Resources) -}} {{- $res := $page.Resources.GetMatch (printf "*%s" $thumb) -}} {{- if $res -}} {{- /* Create multiple sizes for responsive srcset: 400w, 800w, 1200w */ -}} {{- $img400 := $res.Fit "400x" -}} {{- $img800 := $res.Fit "800x" -}} {{- $img1200 := $res.Fit "1200x" -}} {{- $resolved = $img800.RelPermalink -}} {{- $srcset = printf "%s 400w, %s 800w, %s 1200w" $img400.RelPermalink $img800.RelPermalink $img1200.RelPermalink -}} {{- /* Create a tiny low-quality placeholder (LQIP) and base64-encode it for inline use */ -}} {{- /* Try to build a tiny raster placeholder; if not possible (e.g., SVG resource), leave phData empty for now */ -}} {{- with $res -}} {{- $ok := false -}} {{- if (and (isset . "MediaType") (ne .MediaType.Type "image/svg+xml")) -}} {{- $phRes := .Fit "20x" -}} {{- $phB64 := $phRes.Content | base64Encode -}} {{- $phData = printf "data:%s;base64,%s" $phRes.MediaType.Type $phB64 -}} {{- $ok = true -}} {{- end -}} {{- if not $ok -}} {{- /* leave phData empty and we'll generate an inline SVG fallback below */ -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- /* If phData still empty, generate a tiny inline SVG placeholder using category color */ -}} {{- if not $phData -}} {{- $color := "#cccccc" -}} {{- if eq $category "AML" -}}{{- $color = "#ffdd57" -}}{{- else if eq $category "Markets" -}}{{- $color = "#57c7ff" -}}{{- else if eq $category "Science" -}}{{- $color = "#a57cff" -}}{{- end -}} {{- $svg := printf "" $color -}} {{- $b64 := $svg | base64Encode -}} {{- $phData = printf "data:image/svg+xml;base64,%s" $b64 -}} {{- end -}} {{- else -}}
{{- end -}}
