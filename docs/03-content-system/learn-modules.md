# Learn Modules

Learn modules are interactive educational content auto-generated by `scripts/generate_learn_modules.py`. Each module uses Bloom's taxonomy for question scaffolding and includes flashcards for key concepts.

## Module Structure

Every learn module has:

1. **Body content** — Explanatory text with markdown/HTML
2. **Bloom questions** — 3-5 questions at different cognitive levels
3. **Flashcards** — 2-4 key term/definition pairs
4. **Code examples** (data pillar only)
5. **Prerequisites** — Sequential ordering via `seed_learn.py`

## Bloom Taxonomy Questions

Questions span 6 cognitive levels, scaffolded from basic recall to creative synthesis:

| Level | Cognitive Skill | Example |
|-------|----------------|---------|
| `remember` | Recall facts | "What does KYC stand for?" |
| `understand` | Explain concepts | "Explain the purpose of transaction monitoring." |
| `apply` | Use in scenarios | "Given a SAR filing scenario, determine the filing deadline." |
| `analyze` | Break down and compare | "Compare rule-based vs ML-based transaction monitoring." |
| `evaluate` | Critically assess | "Evaluate the effectiveness of OFAC screening controls." |
| `create` | Design and construct | "Design a sanctions screening workflow for a crypto exchange." |

## Flashcards

Each flashcard has a term and definition:

```json
{
  "term": "KYC",
  "definition": "Know Your Customer — the process of verifying client identity..."
}
```

### Flashcard Rendering

In `learn.j2`, flashcards are rendered as interactive toggle cards:
- Front shows the term
- Click reveals the definition
- Multiple flashcards can be cycled through

## Prerequisites

Prerequisite chains are defined in `seed_learn.py:PREREQUISITES`:

```python
PREREQUISITES = {
    "aml/learn/kyc-fundamentals": ["aml/learn/aml-basics"],
    "aml/learn/transaction-monitoring": ["aml/learn/kyc-fundamentals"],
}
```

Modules with prerequisites show a "Prerequisites" section with links.

## Generation Script

`scripts/generate_learn_modules.py` (42,567 bytes) auto-generates learn content:

```
Input:  registry items + seed_learn.py
Output: Updated registry.json with learn module content

Process:
1. For each pillar, identify topic areas needing learn modules
2. Generate body content for each topic
3. Create 3-5 Bloom taxonomy questions
4. Create 2-4 flashcards
5. Generate code examples (data pillar)
6. Set prerequisite relationships
7. Write back to registry.json
```

### Running the Generator

```bash
python3 scripts/generate_learn_modules.py
```

This will:
- Idempotent: won't overwrite existing modules unless `--force` is passed
- Update `registry.json` with new/updated learn content

## Curated Relations

`seed_learn.py:CURATED_RELATIONS` defines cross-pillar connections:

```python
CURATED_RELATIONS = [
    # (source_slug, target_slug, relation_type, label)
    ("aml/learn/kyc-fundamentals", "aml/learn/transaction-monitoring", "prerequisite", "Proceed to Transaction Monitoring"),
]
```

These relations are also used for the knowledge graph and cross-pillar navigation.
