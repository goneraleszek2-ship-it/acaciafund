# Admin Dashboard

The admin dashboard provides 12 pages at `/admin/*.html` for site management and observability. All pages extend `admin/base.html`.

## Template Hierarchy

```
layout.j2  (base site layout: header, footer, dark mode, nav)
  └── admin/base.html  (admin sidebar navigation)
       └── admin/*.html  (12 individual admin pages)
```

**Important:** All admin templates MUST extend `admin/base.html` (not `layout.j2` directly).

## Page Inventory

| Page | Route | Group | Description |
|------|-------|-------|-------------|
| Login | `admin/login.html` | — | Admin authentication (sidebar hidden) |
| Dashboard | `admin/dashboard.html` | Overview | Site metrics summary |
| Quality | `admin/quality.html` | Overview | SQI distribution, threshold failures |
| Coverage | `admin/coverage.html` | Overview | Content coverage by pillar/category |
| Telemetry | `admin/telemetry.html` | Overview | Plausible analytics events |
| Articles | `admin/articles.html` | Content | Content inventory list |
| Gallery | `admin/gallery.html` | Content | Thumbnail gallery view |
| Manifest | `admin/manifest.html` | Content | Build manifest details |
| Pipeline | `admin/pipeline.html` | Content | Build pipeline status |
| Sources | `admin/sources.html` | Intelligence | Source freshness status |
| Ontology | `admin/ontology.html` | Intelligence | Concept/relation CRUD (requires ontology arg) |

## Context Requirements

Each admin page requires `ctx_base` to include:

| Key | Type | Source |
|-----|------|--------|
| `site_name` | str | `config.py:SITE_NAME` |
| `site_url` | str | `config.py:SITE_URL` |
| `username` | str | `.env` or `ADMIN_USERNAME` env var |
| `password` | str | `.env` or `ADMIN_PASSWORD` env var |
| `pages_total` | int | Build output |
| `registry_items` | int | Registry count |
| `sqi_avg` | float | Average SQI |
| `build_timestamp` | str | ISO timestamp |
| `version` | str | Site version |
| `active_page` | str | Current page for sidebar highlighting |

## Generation

Admin pages are generated by `core/build_taxonomies.py:generate_admin_pages()`:

```python
generate_admin_pages(dist_dir, render_template, ctx_base, ontology=None, ...)
```

Scoped to `dist/admin/` directory.
