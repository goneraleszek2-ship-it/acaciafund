# Taxonomy Generation

Taxonomy pages (admin, search, tags, pillar landing pages, feed) are generated by `core/build_taxonomies.py` (958 lines). These are separate from individual content items and are generated once per build.

## Function Overview

| Function | Purpose | Output Files |
|----------|---------|-------------|
| `generate_admin_pages()` | 12 admin dashboard pages | `dist/admin/*.html` |
| `generate_search_pages()` | Search page + client-side index | `dist/search.html`, `dist/static/search-index.json` |
| `generate_tag_pages()` | Tag archive pages | `dist/tags/{tag}/index.html` |
| `generate_pillar_pages()` | Pillar landing pages | `dist/{pillar}/index.html` |
| `generate_feed()` | Atom feed | `dist/feed.xml` |

## Common Signature

All taxonomy generators accept a similar pattern:

```python
def generate_*(output_dir, ..., render_template, ctx_base, ...) -> int:
```

- `output_dir`: `Path` to `dist/`
- `render_template`: Callable (Jinja2 `Environment.get_template().render()`)
- `ctx_base`: Dict with `site_name`, `site_url`, `site_description`, `build_timestamp`

## Admin Pages

```python
generate_admin_pages(dist_dir, render_template, ctx_base, ontology=None)
```

12 pages at `/admin/*.html`, all extending `admin/base.html`:

| Page | Route | Purpose |
|------|-------|---------|
| Login | `admin/login.html` | Admin authentication |
| Dashboard | `admin/dashboard.html` | Site overview, metrics |
| Gallery | `admin/gallery.html` | Content thumbnail gallery |
| Articles | `admin/articles.html` | Content inventory |
| Manifest | `admin/manifest.html` | Build manifest |
| Pipeline | `admin/pipeline.html` | Build pipeline status |
| Quality | `admin/quality.html` | SQI distribution, threshold failures |
| Coverage | `admin/coverage.html` | Content coverage by pillar/category |
| Sources | `admin/sources.html` | Source freshness status |
| Telemetry | `admin/telemetry.html` | Plausible analytics export |
| Ontology | `admin/ontology.html` | Concept/relation CRUD (requires ontology arg) |

Requires `ctx_base` to include:
- `username`, `password` (admin credentials)
- `pages_total`, `registry_items`, `sqi_avg`, `build_timestamp`
- `version` (site version)
- `errors_log_path`, `error_count`

## Search Pages

```python
generate_search_pages(dist_dir, static_dir, all_content, render_template, ctx_base, ontology)
```

Generates two artifacts:
1. **Search page**: Renders `search.j2` → `dist/search/index.html`
2. **Search index JSON**: `dist/static/search-index.json`

Search index entry format:

```json
{
  "slug": "aml/research/suspicious-transaction-reporting",
  "title": "Suspicious Transaction Reporting",
  "content_type": "research",
  "pillar": "aml",
  "description": "Overview of STR filing requirements...",
  "body_truncated": "The filing process involves...",
  "tags": ["sar", "str", "aml"],
  "difficulty": "intermediate",
  "date_str": "2026-06-15",
  "reading_time": 12,
  "sqi": 0.85,
  "concept_boost": ["sar", "str", "suspicious-activity-report"],
  "ontology_concepts": ["str", "aml"],
  "author": "AcaciaFund"
}
```

## Tag Pages

```python
generate_tag_pages(dist_dir, tag_items, render_template, ctx_base, ontology)
```

- Groups content by tags
- Generates `dist/tags/{tag_slug}/index.html` for each tag with ≥1 item
- Tags with ≤2 items get `noindex` meta tag
- Generates `dist/tags/index.html` listing all tags

## Pillar Pages

```python
generate_pillar_pages(dist_dir, pillar_groups, render_template, ctx_base, ontology)
```

- Generates landing pages at `dist/compliance/index.html`, `dist/markets/index.html`, `dist/data/index.html`
- Each page shows pillar-specific content grouped by content_type
- Includes Key Terms section (from ontology concepts for that pillar)

## Feed

```python
generate_feed(dist_dir, all_content, render_template, ctx_base)
```

- Generates Atom feed at `dist/feed.xml`
- Includes up to 30 most recent items
- Each entry has: title, link, id, updated timestamp, summary, categories (pillar, type, tags)
- Feed updated timestamp is the max `created_at` among items (or current time)
