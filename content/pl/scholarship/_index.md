## Współpraca

AcaciaFund jest projektem open-source. Zapraszamy do współpracy!

### Jak możesz pomóc

- **Zgłaszanie błędów** — otwórz issue na GitHub
- **Nowe źródła danych** — zasugeruj API lub feed RSS do dodania
- **Tłumaczenia** — pomoc w rozszerzeniu na inne języki
- **NLP/ML** — ulepszenie modelu klasyfikacji lub generowania pytań Bloom

### Kontakt

Napisz na [contact@acaciafund.org](mailto:contact@acaciafund.org) lub otwórz PR na GitHub.
